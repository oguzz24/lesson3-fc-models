# Домашняя работа 3

Описание установки и запуска: [README проекта](../README.md).
Подробный анализ и таблицы: [REPORT.md](../REPORT.md).

Все три программы можно запускать отдельно, например:

```bash
python homework/homework_depth_experiments.py --datasets mnist cifar10 --epochs 8 --train-limit 6000 --test-limit 2000
```

Глубина означает число Linear вместе с классификатором. В исследовании ширины используются три скрытых слоя.
Регуляризация сравнивается при неизменных размерах [256, 128, 64].

В `results/` сохранены реальные результаты. Каждый `metrics.json` — первичный источник чисел отчёта.
`curves.png` содержит кривые обучения, `weights.png` — гистограммы весов по слоям.
Heatmap grid search находится в соответствующем каталоге датасета.
